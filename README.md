# hemprnd.org 연결용 페이지

`hemprnd.org` 주소로 접속하면 이 페이지가 열리고, 안에서 Google Apps Script 웹앱(실제 사이트)을 화면 가득 보여 줍니다.
방문자 주소창에는 `hemprnd.org/#/projects`처럼 표시되고, 구글 안내 배너는 보이지 않습니다.

## 폴더 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 연결 페이지 본체(앱 주소는 파일 안 `APP_URL`) |
| `CNAME` | GitHub Pages에 알리는 도메인(`hemprnd.org`) |
| `assets/` | 로고, 아이콘, 공유 미리보기 이미지 |
| `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll` | 보조 파일 |

앱 내용을 고치거나 새 버전으로 배포해도 **이 폴더는 바꿀 필요가 없습니다**(같은 배포 주소를 유지합니다).
앱 배포 주소 자체를 새로 만들었을 때만 `index.html`의 `APP_URL`을 바꿔 주세요.

## 1단계. GitHub에 올리기
1. GitHub 저장소(예: `sanmayeon`)를 **Public**으로 만듭니다. (무료 계정의 GitHub Pages는 공개 저장소만 가능)
2. 이 `site/` 폴더 **안의 파일들**(폴더 자체가 아니라 내용물)을 저장소 맨 위(루트)에 올립니다. `.nojekyll`, `CNAME`도 포함합니다.
3. 저장소 **Settings → Pages**에서 *Source*를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 지정합니다.
4. 같은 화면의 **Custom domain**에 `hemprnd.org`를 입력하고 저장합니다.

> 앱 코드(`gas-backend`)와 원본 사진은 이 공개 저장소에 올리지 마세요. 필요하면 **비공개** 저장소를 따로 만들어 보관합니다.

## 2단계. 호스팅케이알 DNS 설정
호스팅케이알의 도메인 관리에서 **DNS(레코드) 관리** 메뉴를 열고 아래처럼 맞춥니다.

**삭제**: 기존 A 레코드 `75.2.85.42`, `99.83.196.71` (기본 대기 페이지용)

**추가**
| 종류 | 호스트(이름) | 값 |
|---|---|---|
| A | `@` (또는 비움) | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `<GitHub 사용자 이름>.github.io` (예: `jcheon94.github.io`) |

- 선택: IPv6용 AAAA 레코드 `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`
- 반영에는 몇 분~몇 시간이 걸립니다.

## 3단계. HTTPS 켜기
DNS가 반영되면 저장소 **Settings → Pages**에서 *Enforce HTTPS*를 체크합니다(인증서 발급에 최대 24시간).

## 권장: 도메인 소유 확인(보안)
GitHub 계정 **Settings → Pages → Add a domain**에서 `hemprnd.org`를 추가하고, 안내되는 **TXT 레코드**를 호스팅케이알 DNS에 넣으면 다른 사람이 같은 도메인을 가로채는 것을 막을 수 있습니다.

## 확인
- `https://hemprnd.org` → 연구회 홈이 열리는지
- `https://hemprnd.org/#/projects` → 프로젝트 화면이 바로 열리는지
- `https://www.hemprnd.org` → `hemprnd.org`로 이동하는지

## 알아둘 점
- 검색엔진은 이 페이지의 제목·설명을 보여 주지만, 안쪽 앱 내용은 잘 읽지 못해 검색 노출이 제한될 수 있습니다.
- Safari 등 일부 브라우저는 다른 사이트 안에 삽입된 화면의 저장 공간을 제한해 "로그인 상태 유지"가 14일보다 짧아질 수 있습니다.
- 화면이 12초 넘게 나타나지 않으면 "새 창에서 열기" 버튼이 표시됩니다(구글 서버 첫 응답이 느린 경우).
